# sim-validation

Controlled simulations with known expected returns, supporting two papers:

- **Module A** — training deep models on low signal-to-noise, non-stationary panels without a validation set
  (when does holdout early stopping degenerate, start dependence, seed divergence, recency weighting);
- **Module B** — the top-of-ranking curse in decision-focused stock selection (score-level propositions B1–B3,
  trained-model tests B4–B6).

The design (Chinese) is `DESIGN_zh.md`. No real data is used: every panel is generated by `sim/dgp.py`.

## Layout

```
sim/dgp.py           synthetic panel (market, switching style premia, drifting linear+nonlinear alpha, t noise)
sim/models.py        MLP regressor (A-M1) and end-to-end score/return net (A-M2)
sim/protocols.py     P1 holdout early stop, P1c cold, P2 purged K-fold, P3 fixed budget, P4 recency, P5 ensemble
sim/score_level.py   module B-I Monte Carlo
run_grid.py          grids, chunked and resumable; one JSON per unit under results/<grid>/
tests/test_basic.py  python tests/test_basic.py
```

## Running

```bash
python tests/test_basic.py
python run_grid.py calib --list
python run_grid.py A_main --chunk 0 --n-chunks 4      # one process per chunk; torch uses 1 thread
```

Each process pins torch to one thread, so results are bit-reproducible for a given unit.
Commit `results/` after each chunk so an interrupted cloud session loses at most one unit.
